# Repository constraints

- This repository distributes portable Codex workflow skills, not an application. Keep reusable instructions in `skills/<name>/SKILL.md` and required resources inside the owning skill. Keep examples independent of particular tools where possible and label behavior specific to a platform.
- Keep `README.md` simple and limited to exactly one Mermaid diagram. Put expanded prompts ready to copy in `docs/WORKFLOW.md`.
- Keep the README and workflow examples consistent when changing the documented process.
- Generic operating policy belongs in the global `~/.codex/AGENTS.md`; add rules here only when they are specific to maintaining this reference repository.
