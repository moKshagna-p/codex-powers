# Repository constraints

- This repository distributes portable Codex workflow skills, not an application. Keep reusable instructions in `skills/<name>/SKILL.md` and required resources inside the owning skill. Keep examples tool-agnostic where possible and label platform-specific behavior.
- Keep `README.md` simple and limited to exactly one Mermaid diagram. Put expanded, copy-ready prompts in `docs/WORKFLOW.md`.
- Keep the README and workflow examples consistent when changing the documented process.
- Generic operating policy belongs in the global `~/.codex/AGENTS.md`; add rules here only when they are specific to maintaining this reference repository.
